## Demo: What's New Controls

- Language: Use the Language select in the Playground header to switch between English and German. The i18n demo schema shows localized labels and option texts.
- Theme: Use the Theme select to switch between Light, Dark, Carbon, and High contrast. Changes apply live to both editor and preview.
- Export: Use the in-Playground Export menu or the header buttons to download the schema and data as JSON.
- Versions: Use Save version, the Versions select, Restore, Export history, and Import history to manage editor state versions in-memory.
- Custom field: Toggle "Custom type: currency" to register a sample custom type aliased to the built-in text field for demonstration.
